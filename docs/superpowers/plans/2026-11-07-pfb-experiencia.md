# Página do PFB como experiência (11 capítulos) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** trocar a página `/produtos/pfb` pelos 11 capítulos de tela cheia da spec v2 (imagem grande, uma frase, creme e azul-noite alternados), com os dois momentos especiais (as lâminas da placa se encaixam e o leque abre), dentro do orçamento de altura, verificada pelo `verificar-pfb`, pelo portão de movimento e por prints.

**Architecture:** a página continua de servidor (`revalidate = 300`) e lê só `carregarLugares()`. Todo texto vive em `src/lib/pfb-textos.ts` (copiado da spec letra por letra, com teste que confere os literais contra a própria spec); a geometria da anatomia vive em `src/lib/pfb-anatomia.ts` (módulo puro, testado). Cada capítulo é um componente em `src/components/pfb/`; os dois de foto inteira (6 e 10) usam `CapituloFoto`. O movimento é só CSS (`animation-timeline` de vista, nível `completo`, sem movimento reduzido); o único JavaScript novo de movimento é `EntradaPfb`, que põe uma classe para o caminho por tempo nos navegadores sem `animation-timeline`. Estado padrão do CSS = estado final.

**Tech Stack:** Next.js 16.2.4 (App Router), React 19.2, Tailwind v4, TypeScript, Node 24 (`node --test` com `*.test.mjs` importando `.ts`), Playwright pelo `PW_CORE` de `scripts/medir-movimento.mjs` (sem dependência nova), `sharp` (já no projeto) para a conferência da anatomia.

**Spec:** `docs/superpowers/specs/2026-11-07-pfb-experiencia-design.md` (v2, commit `a8bce48`), autoridade vinculante. "Tabela" é a tabela "A página, capítulo por capítulo"; "Textos" é o bloco de "Textos finais"; "Movimento" é "Movimento: como é feito"; "Verificação" é a seção de mesmo nome. Leia antes de cada tarefa as linhas da tabela que ela cita. Plano anterior da mesma página, só para convenções: `docs/superpowers/plans/2026-11-07-pfb-e2-pagina.md`.

**Decisões do controlador (07/11/2026), além da spec:**
- A imagem da anatomia no site é `pfb-anatomia-sem-rotulos.webp` (591 × 1410, com alfa, 63 KB); o PNG é a matriz sem perda e não vai para `public/`.
- `pfb-anatomia-recortes.json`: 6 objetos de cima para baixo, `nome`, `poligono` em % da imagem; as lâminas 2 a 6 têm `fechadoY` (% da altura da imagem, em relação à lâmina de cima) e `fechadoVisivelPct` (informativo, não entra no código).
- O encaixe: cada cópia **parte em `translateY(-fechadoY%)` da altura da imagem e `opacity: 0`** e **termina em `translateY(0)` e `opacity: 1`** (o esmaecer cobre o que fica para fora). O quadro final é a imagem original composta. A película (sem `fechadoY`) só esmaece.
